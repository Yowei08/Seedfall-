# Seedfall 音频生成流水线（Python + numpy，零采样、零外部素材）

> 本目录下 21 个 WAV 全部由本目录脚本**从零合成**：没有任何采样素材、没有第三方音频库。
> 依赖只有 numpy（本机无 scipy，所有滤波器/混响/响度测量均自行实现）。
> 版权归本项目，无外部许可问题。

## 一、一键重跑

```powershell

# 生成全部 21 个音频（18 音效 + 3 BGM），并重写 report.txt

& $py "...\verify_audio.py" --strict                                            # 有 FAIL 则退出码 1
```

**环境（已实测）**：Python 3.12.14 ｜ numpy 2.3.5 ｜ 无 scipy。全套跑完约 **130 秒**（4 核）。

### ★ 峰值与 LUFS 为什么不能同时钉死（重要，别再改回去）

`LUFS ≈ 峰值 − 波峰因数 + K 加权偏移`。峰值一旦钉在 −1.00 dBFS，LUFS 就由**波峰因数**决定：

```
曲目         实测波峰因数   峰值钉 −1.00 dBFS 时可达的最低 LUFS
farm_day        12.6 dB                 ≈ −12.0
night           12.2 dB                 ≈ −10.3
```

实测验证（把持续声部一整段 −24…0 dB 扫一遍、混响长度/湿度/房间尺寸全扫一遍）：

| 曲目 | 扫动范围 | 峰值钉 −1.00 时 LUFS 只能落在 |
|---|---|---|
| farm_day | pad+bass −24…0 dB | −12.0 … −16.0 |
| combat | pad+bass −24…0 dB | −11.5 … −12.5（地板，再压不动） |
| night | 混响 0.8–4 s / 湿度 0.08–0.9 / 房间 0.72–0.88 | −10.2 … −10.5（几乎不动） |

**结论**：想让夜晚既 −21 LUFS 又 −1.00 dBFS 峰值，需要 21 dB 波峰因数；本曲材料只有 12.2 dB，
要硬做到就得把鼓点砍到只剩全幅尖峰、中间近乎静音 —— 那不是音乐。
所以本流水线的取舍是：**响度层次是主目标（玩家真正感知到的），峰值 −1.00 dBFS 作为上限约束**
（`master_music(pin_peak=...)`；把 `bgm.py` 里对应曲目的 `pin_peak=True` 打开即可反转为"峰值钉死"）。

## 四、循环判据

1. **长度 = 整数小节 × 拍数**（见上表，`verify_audio.py` 逐文件断言）。
2. **每个音符的尾巴以环绕方式写入**，32 小节的最后一个音自然延续进第 1 小节。
3. **混响用循环卷积**（`circular_convolve`，IR 尾巴折回开头），不是线性卷积后截断。
4. **母带链全部循环安全**：去直流用 `circular=True` 的频域滤波、限幅器增益平滑用
   `circular=True`、软削波无记忆。
5. **BGM 全程不做淡入淡出**。
6. **接缝判据**：`|x[-1] − x[0]|` 必须显著小于文件内相邻采样差的 99.9 分位。

```
file          接缝跳变    占全幅   占 p99.9 正常步长   判定
bgm_farm_day  0.008087   1.44%        12.6%          不可闻
bgm_combat    0.006897   0.97%        10.3%          不可闻
bgm_night     0.001465   0.61%         1.7%          不可闻
```
接缝跳变只占全幅 **0.6–1.4%**（约 −37 dBFS），远小于文件内最大的正常采样步长。

## 六、DSP 参数（"音质与细节"落在这里）

### 1. 包络
每音符独立 `adsr(n, a, d, s, r, gate)`：指数型 attack `(1−e^{−4.6u})`，**最短 1 ms** 由 `max(int(1e-3*sr), …)` 强制；
decay 到 sustain；release 指数至 −60 dB；**末尾 1 ms 强制归零**防尾部残留。
打击乐用 `decay_env(tau)` + 0.3–1.5 ms attack。

### 2. 滤波器（全部自行实现）
- **RBJ cookbook** biquad：低通/高通/带通/峰型/低架。
- **静态滤波**：把 `H(z)` 直接乘到 FFT 网格上（`iir()`），等价于循环卷积——
  `N = 2^k ≥ n + 120 ms` 时局部误差 < −96 dB；`circular=True` 时 `N = n` 精确循环，用于 BGM。
- **时变滤波（滤波扫描）**：块内闭式解 `y[n] = a^{n+1}y[-1] + conv((1−a)x, [a⁰…a^{L−1}])[n]`，
  块长 128，级联 2 级 = 12 dB/oct。实测与逐采样递归差 `2.2e-16`。
  用途：拨弦亮度 8500→1900 Hz 衰减、风声截止受 3 组慢 LFO（0.058/0.094/0.024 Hz）调制、whoosh 带通扫频。

### 3. 乐器
| 音色 | 配方 |
|---|---|
| **Pluck（Karplus-Strong）** | 延迟线 `P = round(fs/f − 0.5)`（减 0.5 补偿均值滤波的半采样延迟）。激励 = 4 段折叠噪声（低方差）+ 6 次谐波 1/k 周期分量（`saw_mix` 0.55，把基频钉住，纯噪声激励会让基频随机埋掉）。每回灌 `decay = 10^(−3/(t60·f))`，阻尼混合 `(1−d)·buf + d·avg`，然后环内低通自带上限。音高误差 ≤ ±4 cents（D2–D5）。 |
| **Pad** | 3 个失谐锯齿（±8…12 cents），**加性带限波表**（每个音符按 Nyquist 选谐波数，绝不混叠），biquad 低通 1500–2100 Hz，ADSR a 0.30–1.4 s / r 0.8–2.4 s，起音期还有 520→1500 Hz 的开合扫描。 |
| **Bass** | 正弦 + 0.22 三角，低通 420–1100 Hz，`tanh` 轻微饱和（1.15–1.9）。 |
| **Bell** | 双算子 FM，调制比 2.0 / 3.0 / 3.5（3.5 = 7:2 非谐和玻璃感），调制指数 1.6–7.0 随 0.03–0.45 s 衰减。 |
| **Percussion** | kick：正弦下滑 120→45 / 130→46 / 60→30 Hz + 击槌噪声 + `tanh` 驱动；snare：1.9–2.6 kHz 带通噪声 + 185 Hz 短体；hat：7.2 kHz 高通噪声 + 4 音金属簇；shaker：2.6 kHz 高通→5.2 kHz 带通噪声。 |
| **Wind** | 噪声 → 时变低通 120–2400 Hz（3 组慢 LFO 驱动）→ 时变高通 → 极慢幅度呼吸。循环长度直接生成为整段，天然可循环。 |

### 4. 混响
**Freeverb 风格**：8 条阻尼梳状（1116/1188/1277/1356/1422/1491/1557/1617 采样 @44.1k，右声道 +23 解相关）
→ 4 级 Schroeder 全通（556/441/341/225，g=0.5）。梳状反馈里的**一级低通就是"尾巴越衰减越暗"的物理来源**。
IR 按**单位能量**归一（`Σh² = 1`），所以卷积是能量守恒的，`wet` 才是可解释的增益。

| 曲目 | room | damp | 预延迟 | IR 长度 | wet | 实测 wet/dry |
|---|---|---|---|---|---|---|
| farm_day | 0.80 | 0.42 | 18 ms | 3.0 s | 0.85 | **−13.5 dB** |
| combat | 0.72 | 0.30 | 8 ms | 1.8 s | 1.50 | **−15.6 dB**（最紧） |
| night | 0.88 | 0.55 | 28 ms | 4.0 s | 0.90 | **−5.0 dB**（最湿，空灵） |

音效按需选 3 档：`REV_SMALL`(0.55 s) / `REV_MID`(1.2 s) / `REV_LARGE`(2.6 s)，每个效果自带 send 量
（click/hover 完全干声，blast/defeat 送 0.55）。

**按轨道给不同 send 量**：farm（pluck 0.30 / pad 0.26 / bass 0.04 / perc 0.13 / bell 0.42）、
combat（arp 0.17 / pad 0.14 / bass 0.03 / drums 0.10）、night（bell 0.52 / pad 0.34 / wind 0.10 / bass 0.30）。

### 5. 立体声
- **恒定功率 pan**：`L = cos((p+1)π/4), R = sin((p+1)π/4)`。
- **Haas 延迟**做宽度：pad 9 ms、night pad 14 ms、pluck 6 ms、bell 11–12 ms（单侧延迟，不抵消中置）。
- **声部 pan**：farm pluck +0.13 / pad ±0.45 分层 / perc −0.25…+0.34 / bell −0.38；
  combat arp 在 −0.30…+0.30 之间随十六分音符**扫动**。
- 实测左右相关度 < 0.999（`verify_audio.py` 断言"是真立体声"）。

### 6. 总线与母带
```
BGM ：stems → pan/Haas → dry + mono send → Freeverb（循环卷积）
     → 18 Hz 去直流（循环频域）→ tanh glue(drive 1.06)
     → 压缩（th= −15 dBFS, ratio 1.75, 前瞻 4 ms, release 200 ms, 循环）
     → [增益至目标 LUFS → 前瞻限幅 ceiling −1.0 dBFS] × ≤6 次
     → 峰值上限 −1.0 dBFS → TPDF dither → 16 bit

SFX ：layers → pan → dry + send → Freeverb（线性卷积）
     → 去直流 → 峰值归一到 −1 dBFS（增益级）→ tanh glue(1.05)
     → 压缩（th −13 dBFS, ratio 1.9, 前瞻 2 ms, release 90 ms）
     → [增益至 −12 LUFS → 超限才限幅] × ≤6 次
     → 去直流 ⇄ 淡变交替 4 次（两个残差同时收敛）→ TPDF dither → 16 bit
```
**限幅器**：`gain = min(one_pole_smooth(slide_min(ceiling/env, 1.5×前瞻), release), slide_min(...))`
—— 用 Gil-Werman 滑窗最小值做前瞻、再用一级低通做释放，并与未平滑曲线取 `min` 保证不过冲。
实测：+9.5 dBFS 尖峰压到 **−1.0000 dBFS**，信号未超限时增益偏差 < 0.05 dB。

### 7. 响度测量（BS.1770-4）
K 加权两段（+4 dB 高架 1681.97 Hz / Q 0.70718，38.14 Hz 高通 / Q 0.50033）由**双线性变换按任意采样率重推**，
与标准公布的 48 kHz 系数表逐位比对 **maxdiff 8.88e-16**；997 Hz 满幅立体声正弦读 **−0.044 LUFS**（校准正确）。
BGM 用带门限的 integrated（400 ms 块 / 100 ms 跳，−70 LUFS 绝对门 + −10 LU 相对门）；
SFX 用整段未门限值（单发音效用门限没有意义，已在报告里注明）。

### 8. 归一化与量化
- 峰值上限 = `floor(10^(−1/20)·32767) = 29202`，Unity 按 `i16/32768` 解码即 **−1.0006 dBFS ≤ −1**。
- **TPDF dither ±1 LSB** 加在量化前，随后再夹到同一上限，dither 不可能把峰值顶过界。
- 每文件独立种子（`crc32(文件名)`）。

| **BGM**（3 首，10–16 MB） | **Streaming** | **Vorbis, quality 0.7** | 长音频不占常驻内存；`Loop` 打勾 |
| **SFX**（18 个，< 220 KB） | **DecompressOnLoad** | **PCM** | 短音效要零延迟、无解码抖动 |

> 循环点在 Unity 里能对上，是因为文件长度是整数小节；`Loop` 打开即可无缝，
> 若引擎侧再叠一层 crossfade 反而会在接缝处出现双重尾巴。

`.meta` **未随本流水线提交** —— 首次导入由 Unity 生成，再按上表手工调一次即可。

## 八、没做到 / 已知限制（如实写）

1. **没有做真正的母带多段压缩、没有真峰值（True Peak）过采样检测**。
   限幅器工作在采样峰值（sample peak）上，4× 过采样后的真峰值可能比 −1.0 dBFS 高 0.1–0.4 dB。
   若要在广播链路里严格达标，需要在限幅器里加 4× 过采样检测。
2. **音乐没有做侧链（sidechain）**：bass 与 kick 不会互相让路，靠静态分轨电平平衡。
3. **波峰因数不可控**：见第三节 —— 想让夜晚在 −1.00 dBFS 峰值下达到 −21 LUFS，需要重新作曲（更稀疏、更长静默），
   调参数做不到。
4. **拨弦是整数延迟线**，音高量化到 ±4 cents（D6 附近可到 ±12 cents）。要更准需要分数延迟全通，会牺牲矢量化的速度。
5. **Karplus-Strong 的激励是"折叠噪声 + 周期分量"**，不是纯噪声。纯噪声更"物理"，但基频随机埋没、听感发虚，
   这是刻意的取舍，不是遗漏。
6. **每个音效只有一层发送混响**，没有做"近场/远场双层"或卷积房间。
7. **`night` 的 wet/dry 是 −5.0 dB**（混响能量约为干声的三分之一），刻意做得很湿；
   如果后期觉得糊，改 `bgm.py` 里 night 的 `reverb["wet"]` 一个数即可。
8. **没有做 5.1 / 空间音频**，只有立体声。
9. **响度门限对 < 400 ms 的音效不适用**，所以音效用未门限整段值（已在报告列头注明）。
