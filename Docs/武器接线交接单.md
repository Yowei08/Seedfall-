## 2. ★ 挂点：一次对齐，不用试角度 ★

```csharp
var hand = player.transform.Find("Armature/Bone_Hand_R");
weapon.SetParent(hand, worldPositionStays: false);
weapon.localPosition = Vector3.zero;
weapon.localRotation = Quaternion.Euler(0f, 180f, 0f);   // ← 三把武器【同一个值】
```

**为什么三把武器能共用同一个旋转**：subagent 把**握持朝向烘进了网格顶点** ✓
每把武器的 `GRIP` 节点都在原点、旋转为单位四元数 ✓
握持坐标系的定义：**手柄沿 +Z，掌心法线沿 +X** ✓
在手腕局部系里要转成"手柄竖直、法线朝前"，实测正好是绕 Y 轴 180° ✓

**`Bone_Hand_R` 的 rest 世界位置 = `(-0.33, 0.96, 0.0)`** ✓

## 4. ★ "边跑边挥锄头"：两段采样，不需要 Avatar Mask ★

**本工程没有 Animator** ✗ —— `ModelView` 用 `AnimationClip.SampleAnimation` 手驱 ✓
全工程 `Animator|AvatarMask|Playables` **零命中** ✓

所以 **Avatar Mask 无处可挂**（它是 Animator 分层 Layer+Mask 的概念）✗

**但效果照样拿得到，而且更直接**：

```csharp
_moveClip.SampleAnimation(_animRoot, moveTime);      // idle / walk 管下半身
_attackClip.SampleAnimation(_animRoot, attackTime);  // attack 管上半身
```

**为什么不会互相覆盖**：三套 attack 与 swap 的**腿骨曲线恒为 0** ✓
（逐帧实测：`Thigh_L/R`、`LowerLeg_L/R`、`Foot_L/R`、**`Hips`** 全部 `0.0000°`）

> **`Hips` 也锁了是刻意的** —— 它是腿的父节点，转髋会连带转整条腿，
> "下半身维持移动或站立"就失效了 ✓

## 7. 两个已知的坑

**① 玩家缩放**：`SetScaleFactor(CharScale * PlayerScale)` 是**绝对倍率，不按身高归一** ✗
新模型 1.839m 配 `PlayerScale = 0.627` 才得到 3.00m ✓（已改好）
**若以后换模型，这个值必须重算** ✗ —— 或者改成 `ScaleToHeight(3.0f)` 一劳永逸 ✓

**② `ModelView` 的 `MeshRawHeight` 已修**：原实现用"本地尺寸 × 缩放"**忽略旋转** ✗
导致旋转过的部件高度被低估几十倍 → 模型被放大 76 倍（实测 136m 的豌豆射手）✓
