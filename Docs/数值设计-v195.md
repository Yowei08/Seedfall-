## 0. 结论：两条数学冲突的解法（不静默选择）

### 冲突① 「血 10」 vs 「普通敌人 8 下致死」

判据式：`下数 = ceil(血 / 每下整数伤害)`，每下伤害 = `max(1, round(曲线值 × hpUnit))`，`hpUnit = 1`。

| 目标 | 需要的整数伤害 | 10 血下的可能落点 |
|---|---|---|
| 普通 / 弹幕 **8 下** | `d ∈ [10/8, 10/7) = [1.25, 1.43)` | **空集**（d=1 → **10 下**；d=2 → **5 下**） |
| 精英 **5 下** | `d ∈ [2, 2.5)` | d = 2 ⇒ **5 下 ✓ 精确** |
| BOSS **3 下** | `d ∈ [3.33, 5)` | d = 4 ⇒ **3 下 ✓ 精确** |

- **要三条全精确，血必须是 120 的倍数**（`LCM(8,5,3)=120` ⇒ d = 15 / 24 / 40）。**血 = 24** 也能全中（d = 3 / 5 / 8），但 24 ≠ 用户点名的 10。
- **本轮裁决**：**保留血 10**（用户逐字给的值，且"回调"就是回到 10），让"8 下"落到**整数格上更安全的那一侧**：`d = 1` ⇒ **10 下**。
  - 为什么不取 `d = 2`（5 下）：那样**普通兵与精英的致死下数完全相同**（都是 5 下），伤害阶梯塌陷，精英失去身份 ✗
  - 为什么不改血：血 10 是本轮的**目标刻度**本身，改了它等于把"回调"做成"新平衡" ✗
- **如实报**：`8 下` 未达成，实测 **10 下**（容错方向：玩家更耐打）。`5 下 / 3 下` **精确达成**。

### 冲突② 「30 分钟传奇 2000」 vs 「普通商品以百为单位」

实付价 = `基础价 × 档位倍率 × 波次倍率 W(30)`。改前：基础价 D5~S80（种子）与 D5~S22（道具）、档位 1/1.8/3.2/5.6/**9**、`W(30) = 1.13^29 × 2.0 = 69.2` ⇒ **S = 198×69.2 = 13708**（破万 ✗）、D = 346。

- 两条要求**正好把 W(30) 夹死**：`S 2000 ⇒ W(30) ≤ 2000/(80×5.0) = 5.0`；`D ≥ 100 ⇒ W(30) ≥ 100/(20×1.0) = 5.0` ⇒ **W(30) = 5.0（唯一解）**。
- ⇒ `(1+s)^29 × post20(30) = 5.0`，取 `post20PriceSlope = 0.05`（×1.5）⇒ `(1+s)^29 = 3.3333` ⇒ **`priceWaveStep = 0.04239`**（0.0424 会算成 2001，差 1 点就破线）。
- ⇒ 档位倍率必须**压 S**：`1 / 1.8 / 2.8 / 3.8 / 5.0`（改前 9.0 ⇒ 80×9×5 = 3600 ✗）。
- ⇒ 同时**道具基础价对齐种子**：D20 / C30 / B40 / A60 / S80（改前道具 5~22 ⇒ 30 分钟 D 档只有 25，两位 ✗）。
- 结果：**30 分钟 D 100 / C 270 / B 560 / A 1140 / S 2000**，比值 S:D = **20:1**，**没有任何商品 ≥ 10000**。

## 8. 负数属性处理（第二轮追加需求）

### 现状查证（用户要求先查）
- `StatBlock.Evaluate` 改前**只有上限裁剪**（`caps`），**没有任何下限** ⇒ **负值原样保留** ⇒ 表里的减益（玻璃大炮 −1 血、狂战面 −8% 移速…）**一直是生效的**（不是 bug）。
- `caps` 里全是**上**限，**下限一个都没有**。

### 新下限表（`StatBlock.FloorOf`，唯一实现）

| 属性 | 分数属性 | 负值怎么处理 | 下限 | 理由 |
|---|---|---|---|---|
| 近战 / 远程 / 爆炸伤害 | 否 | **存储保持负；代入公式时当 0** | 无（−∞） | 面板要看得到减益，但 `(基础 +(−3))` 不许低于基础 ⇒ `NonNegativeDamageStat` |
| 最大生命 | 否 | 钳到下限 | **1** | 0 血 = 立刻死亡 + 血条百分比除零（NaN 进 UI）；1 离开局 10 血仍有 9 点余量 |
| 护盾 / 爱心恢复 / 爱心掉落率 / 小猪刷新率 / 暴击率 / 幸运 / 闪避 / 击退 | 部分是 | 钳 0 | **0** | 血量、等级、概率不能为负 |
| 可种植株数 | 否 | 钳 1 | **1** | 列数 0 会让田地形状退化 |
| 伤害倍率 / 攻击速度 / 攻击范围 / 移动速度 / 暴击伤害 / 爆炸范围 | 否 | 钳 0.1 | **0.1** | 攻速 = `冷却 / atkSpeed` ⇒ 0 是除零、负是负间隔；倍率为负 ⇒ 伤害为负 |
| 经验倍数 / 货币倍数 | 否 | 钳 0 | **0** | 0 是合法（严酷）减益，且不除零 |
| 其它未登记属性 | — | **不钳** | −∞ | 漏登记必须**可见**（自检有一条钉"每条属性都登记了下限"） |
