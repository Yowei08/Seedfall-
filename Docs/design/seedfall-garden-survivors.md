## 一句话内核

你是最后一位守园者：**把种子种成战友，用地换时间，用时间换火力**。
每局重复动作：跑位躲伤害 → 抽空掘地/播种/洒水/施肥 → 看植物替自己打 → 捡钱升级 → 再耕一块地。动机回路是**「耕地越多 → 火力越强 → 越能空出手开下一块地」的正反馈飞轮**，波次是它的计时器。

**三条不可丢的差异点**
1. 战力由玩家**在时间压力下亲手生产**，不是自动获得。
2. 战力**持久占位**：植物被打死即战力归零 → 独有"护田"防线。
3. 战斗与耕作**竞争同一段时间**（耕作定身、武器与耕作共用操作）——实测证明「时间」才是真正的瓶颈资源。

## 核心循环

| 阶段 | 时长 | 玩家在做什么 |
|---|---|---|
| 开局准备 | 30s（可提前） | 三选一 D 级种子 |
| 战斗波次 | 30–50s（Boss 波有时限） | **前 10s 种植免刷怪** → 掘地/播种/洒水/施肥 → 护田 → 打怪 → 捡钱 |
| 波间商店 | 20s（可跳过） | 买种子/道具、出售、刷新 |
| 结算 | — | 胜利 / 失败 → 重开 |

### 单波内的节奏（v3 关键）
```
波次开始 ──10 秒种植时间（不刷怪）──► 开始刷怪 ──[时长到 且 场上清空]──► 波次结束
   种植时间：掘地 2.0s + 播种 1.0s + 生长 4.2s（洒水×0.7、施肥×0.5）≈ 一块地 8.2s
   一块地差不多用满 10s → 目标"第一波前开 1 块地，边打边补"
```
- **耕作进度跨操作保留**：开垦到一半停下（走位、换目标）进度不清零，下次从原处继续推进。
- **回合结束刷新田地**：所有地块回到"未开垦"、植物清空（战力不跨波，每波重新生产）。
- **普通波硬上限** `时长 × 1.35` 强制收尾（防"只跑不打"软锁）；**Boss 波限时 120s**，超时未击杀判负。

### 单块耕地状态机
```
空地 ──掘地 2.0s/攻速──► 已掘地 ──播种 1.0s/攻速──► 生长中(幼苗)
   生长中：洒水 0.5s（生长×0.70）｜施肥 0.5s（生长×0.50）乘法叠加，下限 ×0.35
   幼苗：**不可被攻击**（敌人不索敌、弹道穿透、AoE 免疫）
   生长归零 ──► 成株（可被攻击，开始自动索敌作战）
   成株被打死 / 回合结束 ──► 空地
```
> 设计意图：把"浇完水就能安心"变成"浇完水还要等它长大"，同时**幼苗免伤**让 10 秒种植窗口真正可用。

### 伤害与辅助公式
```
攻击 z = (x + y·m)·n·crit        crit = 1 或 critDmg；z ≥ 0.1
恢复 q = (x + regen·0.80)·n
护卫 q = (x + maxHp·0.35)·n      【只继承最大生命值】
汲取 w = z·(0.1 + leech)         【仅植物攻击触发】
```
**异常（v5）**：毒生效延迟 **2.0s**、其余异常 1.5s；状态子弹额外造成 **异常值×0.5** 命中伤害；**带毒的敌人接触（1.2m）会把毒传染给未中毒的敌人**（每次最多 2 个、传染 30% 且 1.5s 冷却，比值递减不会爆炸）。累积后按各自延迟引爆 —— 中毒 `0.06·累积`/0.5s×4s 且 30% 转玩家生命；烧伤 `0.08·累积`/0.5s×4s 并向 2.5m 内 2 个敌人传递 30%（不再产生新烧伤）；冰冻累积 ≥ `max(maxHp×0.5, 4)` 冻结 2.5s，破冰 `1.2×累积`。

**植物继承**：生命 `baseHp × 玩家maxHp/10`｜护盾 `baseShield × 玩家shield/2`｜攻击 `(x+y·m)·n`｜间隔 `interval/攻速`｜射程 `range×范围`｜移速 `moveSpeed×玩家移速/5`。

## v5 新增：种子品质与合体

| 档位 | 白 | 绿 | 蓝 | 紫 | 金 |
|---|---|---|---|---|---|
| 数值倍率（攻击与生命） | ×1.00 | ×1.15 | ×1.32 | ×1.52 | ×1.75 |
| 商店权重 | 50 | 27 | 14 | 7 | 2 |

- **合体**：持有**两个同种同品质**的种子 → 点击两个槽位合体，品质 +1 并立即获得数值成长（白→绿→蓝→紫→金，金为上限）。
- 种子袋**允许同名重复持有**（重复种子就是合体材料）；种植本身**不消耗**种子（无限）。
- 商店价格随品质缩放（如 8 金的 D 级种子在绿品质下卖 9），变异种子固定为**金色品质**。
- 品质在**播种时**结算进植物：植物生命 = baseHp × (玩家maxHp/10) × 品质倍率，攻击同乘。

## v6 新增：耕地按需生成 + 工具升级

### 耕地（gridSize 5 / initialPlots 6 / levelsPerPlot 10 / caps.maxPlots 25）

| 项 | 规则 |
|---|---|
| 地图上有什么 | **只有已获得的地块**（开局 6 块），围栏也只圈住已有范围，不预示未来地块 |
| 获得方式 | **每 10 级获得 1 块**（Lv10 → 第 7 块，Lv20 → 第 8 块 …），上限 25 块（5×5 满格） |
| 生成位置 | 与已有耕地**相邻**：横向邻接优先，其次靠近簇心；保证永远连着，不会出现飞地 |
| 加入场景 | 新地块加入时即时建模型并闪一下提示（`WorldView.EnsurePlotTiles`） |
| 回合重置 | 只把地块刷回"未开垦"，**不删地块**（耕地只增不减） |

> ⚠ R-16：10 波内几乎拿不到新耕地。实测实机到 Lv10 才拿到第 7 块；而四个 Bot 都在 Lv3–4 阵亡，一局实际只有 6 块。若要更早吃到成长：① 改成每 5 级 +1；② 初始 4 块 + 更快曲线；③ 商店加"开垦许可证"道具（+1 耕地）。

### 工具升级（与种子同一套品质机制）

| 工具 | 对应动作 | 数值成长 | 工作能力 |
|---|---|---|---|
| 锄头 | 掘地 | 物理伤害 ×品质倍率（1.00/1.15/1.32/1.52/1.75） | 掘地同时 **1+品质** 块（上限 4） |
| 水壶 | 洒水 | 法术伤害 ×品质倍率；每档额外 **−5%** 生长 | 洒水同时 **1+品质** 块（上限 4） |
| 肥料 | 施肥 | 异常伤害 ×品质倍率；每档额外 **−4%** 生长 | 施肥同时 **1+品质** 块（上限 4） |
| 播种手套 | 播种 | —（纯功能件） | 播种同时 **1+品质** 块（上限 4） |

**升级规则（= 种子同款）**：未拥有 → 直接获得该品质；**同品质再买 → 合体升一档**；买到更高品质 → 直接替换；更低品质 → 拒绝（已有更好的）。
**横向拓展**：一次动作作用的地块 = 目标地块 + 同一行最近的地块（左优先），只挑"当前动作适用"的地块，数量不超过工作能力。

商店权重调整为：种子 55 / 永久属性道具 25 / **工具 20**。

## v7：合成自动化与操作收敛

| 项 | 规则 |
|---|---|
| 种子袋切换 | **数字键 1–6** 切换当前槽位；点击槽位同样可切换（不再需要"点两次手动合体"） |
| 锁定模式 | `G` 锁定后**鼠标左键不再触发主动攻击**，也不会改变瞄准方向；锁定时只朝锁定目标自动攻击 |
| 非锁定模式 | 左键仍然朝鼠标方向主动攻击（v5 规则不变） |
| 合成（商店） | 「合成」按钮：包内存在**两个相同**（同种同品质）的种子时可用，一键**反复合成**直到没有可合成的一对（4 白 → 2 绿 → 1 蓝） |
| 合成（满袋） | 种子袋已满时买入与袋中相同的种子 → **自动合成**（该槽品质 +1，不占新槽）；若袋满且无相同种子 → 拒绝购买并提示 |
| 武器升级 | 商店买到的锄头/水壶/肥料**购买即自动合成升级**（同品质 → 升一档；更高品质 → 直接替换；更低 → 拒绝） |

### 为什么这样改（设计意图）
- "点两次合体"是一个纯操作负担：合成的**决策**（要不要合、合哪个）没有变，但**执行**变成了两步点击。改成按钮 + 满袋自动合成后，玩家的注意力回到"买什么"上。
- 满袋自动合成解决了上一版暴露的死结：种子袋 6 槽允许重复持有（合体材料），但袋子一满就无法再买种子 → 现在"买相同种子"本身就有意义（等于花金币买一次品质提升）。

## v8：耕作与战斗互斥（采纳 E-02 加严版 + E-03）

### 规则
| 项 | 规则 |
|---|---|
| 耕作期间 | **禁止任何攻击**：左键主动攻击、锁定目标的自动攻击、兜底自动攻击全部失效（`FarmingThisFrame` 门控） |
| 耕作结束 | 松开 `E`（或地块不再需要操作）后，攻击**同一帧恢复** |
| 表现 | 右侧武器面板显示「耕作中（无法攻击）」；左侧说明补注 |
| 耕地成长 | `levelsPerPlot 10 → 5`：**每 5 级 +1 块**（Lv5 → 7 块，Lv10 → 8 块 …，封顶 25） |
| 开垦许可证 | 商店道具：`MaxPlots +1`，70 金，最多叠 4 张（与等级成长叠加） |

### 设计意图
"边种边打"必须消失：耕作是**放弃输出与自保**去换取产能。之前玩家在耕作时仍能自动开火，等于零成本耕作，耕作占比被推到 61–78%。现在两条时间线互斥，取舍由玩家做。

### ⚠ 关于"耕作占比"这个指标（重要）
这条规则生效后，占比**没有下降**（Balanced 62.7% → 73.1%），原因是：
1. 占比 = 耕作时长 / **战斗总时长**；耕作禁止攻击后清场变慢、**玩家更早阵亡**，分母缩短 → 占比被动上升。
2. Bot 的耕作**时长**本身没变（它一直想种地），规则改变的是"耕作时的输出"，而不是"耕作的意愿"。
因此**应该换指标**：本次已加入 **耕作挨打次数**（`FarmHits`，`Docs/reports/` 报告里已输出），它直接回答"耕作有没有代价"：
- **Farmer（只种地不打架）= 13 次挨打** —— 贪婪被打的代价可见；
- **Balanced / Rush（先清场再种地）= 0 次** —— 会取舍的打法不吃这个亏。
这才是这条规则的价值证据。

## v9：异常三系重做 + 养成收敛

### 自动锁定
| 行为 | 规则 |
|---|---|
| 开启 | 按 `G` 开启自动锁定（**不需要场上有敌人**，开关状态保留） |
| 选目标 | 永远锁**离自己最近**的敌人 |
| 切换 | 出现更近的敌人 → **自动改锁**；目标死亡 → 自动改锁最近的；场上清空 → 保持开启，等下一个敌人出现 |
| 攻击 | 锁定中只朝锁定目标自动攻击；**耕作期间全部失效**（v8 规则） |

### 异常三系（全部重做）
| 异常 | 触发 | 结算 | 特性 |
|---|---|---|---|
| **毒** | 命中即中毒 | **每 1 秒一次，共 4 次**（`poisonTickFactor 0.15`） | 结算伤害的 30% 转为玩家生命；**健康敌人贴身接触满 1 秒**被扩散（`poisonContactSeconds 1.0`） |
| **火** | 命中即灼烧 | **每 1 秒一次，共 4 次**（`burnTickFactor 0.18`） | **灼烧中的敌人被"非异常"攻击命中 → 爆炸**：半径 2.2m 内其它敌人受到该次伤害的 50%（不产生新灼烧，防链式） |
| **冰** | 命中进入寒冷 | 每次"非异常"命中 **+25% 寒冷**（+1 层，最多 4 层） | 每层 **−20% 移速**；满 4 层 → **冰冻 1 秒（禁止移动）** → 随后**破冰伤害 = 累计承受的非异常伤害 × 1.2** |

### 植物判定范围
`DetectM = 攻击范围 × plantDetectFactor(1.35)`：
- 判定范围内**有敌人** → 扑向敌人（到 0.85×攻击范围处输出）；
- 判定范围内**无敌人** → 靠拢**玩家**（而不是回原地），植物跟着玩家走。

### 道具等级与定价
- 道具分 **D / C / B / A / S** 五档（`items.json` 每件带 `grade`）。
- **刷新率**：等级越高基础权重越低（50/28/15/6/1）；**随波次提高**高等级权重、**幸运**再加成（`luckRefreshBonus 0.6`）。
- **价格 = 基准价 ×(1 + 0.45×等级档位) ×(1 + 0.03×(波次-1))**（种子的价格额外乘品质倍率）。

| 项 | v10 规则 | v12 规则 |
