### 伤害公式

用户口径的三段式，代码里**只有一个实现**（`Combat.cs:202 / 278 / 286`）：

```
普通一击   = (武器基础值 + 对应类型伤害) × 伤害倍数 × 暴击
           = AttackFormula(baseValue, damageStat, atkMult, crit, critDmg, minDamage)
           = max( minDamage , (baseValue + damageStat) × atkMult × (crit ? critDmg : 1) )
           其中 minDamage 默认 1（Combat.cs:203）

肥料伤害   = 上面那条算完 × 爆炸倍率
           = WeaponBlastDamage(...) = ExplodeFormula(WeaponDamage(...), explodeMult)
           = max(0, 普通一击 × explodeMult)

暴击       = 每次攻击按 Clamp01(critRate) 掷一次（RollCrit），命中则**整条算完的伤害**再乘 critDmg
```

- 锄头 `damageStat` = `MeleeDamage`；水壶 = `RangedDamage`；肥料 = `BlastDamage`。
- **公式里没有"品质"这一项**（`WeaponSystem.cs:266` 明确删除）；`quality.mult` 全为 1.0（`tuning.json:244`）。

**开局（零道具、零升级）三把武器的实际伤害**

| 武器 | 普通 | 暴击（×1.5） | 算式 |
|---|---|---|---|
| 锄头 | **4.00** | **6.00** | `(4 + 0) × 1.0`；暴击 `4 × 1.5` |
| 水壶 | **3.00** | **4.50** | `(3 + 0) × 1.0` |
| 肥料 | **12.50** | **18.75** | `(5 + 0) × 1.0 × 2.5`；暴击 `12.5 × 1.5` |

> 这也解释了 `enemies.json` 里那条「开局一刀死」的注：`ceil(2.8 / 4) = 1`。
> ⚠️ 那条注写的是「锄头 baseValue **3** + player.meleeDamage **1** = 4」—— **现在表里是 baseValue 4 + meleeDamage 0**（`tuning.json` 的 `tools.hoe.baseValue` / `player.meleeDamage`）。**和数仍是 4**，结论不变，但注里的拆法是旧数据。

### 3.2 成长曲线：五套 `(a, b)`

公式在 `Defs.cs:1203`：

```
WaveGrowth(wave, a, b) = 1 + a·t + b·t²        t = max(0, wave − 1)
```

`t` 就是「第几分钟减一」（第 20 分钟 ⇒ `t = 19`）。`t = 0 ⇒ 恒 1.0`，这是「第 1 分钟数值 = base 值」的保证。

| 曲线 | 系数键（`tuning.json: enemies`） | a | b | b/a | 第 20 分钟倍数 |
|---|---|---|---|---|---|
| 标准 HP（`pig` / `grunt` / `shooter`） | `hpStepA` / `hpStepB` | **0.744168** | **0.0372084** | 5.0% | **28.571424** |
| 精英 HP（`Jumper`） | `eliteHpStepA` / `eliteHpStepB` | **0.294326** | **0.01471628** | 5.0% | **11.904771** |
| BOSS HP | `bossHpStepA` / `bossHpStepB` | **0.2699055** | **0.01349528** | 5.0% | **11.000001** |
| 标准伤害（五种共用） | `dmgStepA` / `dmgStepB` | **0.204357** | **0.0102179** | 5.0% | **8.571445** |
| BOSS 伤害 | `bossDmgStepA` / `bossDmgStepB` | **0.10153589** | **0.00507679** | 5.0% | **4.761903** |

五条曲线**形状相同**（`b/a` 全为 5%）、只有振幅不同 —— 这是 v190 解系数时定下的形状比（`tuning.json` 的 `_note_v190_solve`：`f(19) = 1 + 19a + 361×0.05a = 1 + 37.05a`）。

```

  精英 HP：  a = (11.904762 − 1)/37.05 = 0.294326  ✓
  BOSS HP：  a = (11.000000 − 1)/37.05 = 0.2699055 ✓
  标准伤害： a = (8.571429 − 1)/37.05  = 0.204357  ✓
  BOSS 伤害：a = (4.761905 − 1)/37.05  = 0.10153589 ✓
```

### 3.3 前段压低（`earlyNerf` / `earlyNerfEnd`）

`Defs.cs:1252`（唯一实现，`HpForWave` 与 `DamageForWave` 都只用这一个）：

```
t = max(0, wave − 1)
t ≥ earlyNerfEnd        ⇒ 1.0        （精确，不带残差）
t < earlyNerfEnd        ⇒ 1 − earlyNerf × (1 − t/earlyNerfEnd)²

代入表值 earlyNerf = 0.35 、earlyNerfEnd = 8.0：

第 1 分钟 t=0 ⇒ 1 − 0.35 × (1 − 0/8)² = 1 − 0.35 = 0.65
第 2 分钟 t=1 ⇒ 1 − 0.35 × (0.875)²  = 0.732031
第 3 分钟 t=2 ⇒ 1 − 0.35 × (0.75)²   = 0.803125
第 5 分钟 t=4 ⇒ 1 − 0.35 × (0.5)²    = 0.912500
第 9 分钟 t=8 ⇒ 1.0（窗口结束，此后精确 1）
```

**BOSS 不吃这一项**：`HpForWave` 在 Boss 分支里直接 `return`（`Defs.cs:1337-1338`），`DamageForWave` 用 `if (Kind != Boss)` 才乘（`Defs.cs:1353`）。所以 BOSS 任何波次都是原值。

> ⇒ 真正刷出来的 BOSS 血量（含序号加成）：**第 10 分钟 1492.35｜第 15 分钟 2672.55｜第 20 分钟 4290.00**。

> 两者不矛盾，但**报表要看是哪一个**：3300 是曲线值，4290 是第 20 波真刷出来的值。**`待确认`：哪一个才是设计意图中的「第 20 分钟 BOSS 血量」**（目标带 3000~3500 只涵盖前者）。

### 5.1 派生公式（角度 / 间隔 / 伤害比这类，全部写清）

聚合规则在 `WeaponSystem.Aggregate`（`WeaponSystem.cs:200-258`），纯算式在 `WeaponSystem.cs:330-450` 与 `RunSession.cs:4658-4752`。

**剑气（`hoe_swordwave`，amount = 1 道/层，maxStack 3）**

```
剑气道数        = SwordWaveCount += round(amount × 层数)        每层 +1 道
一道剑气的伤害  = 锄头**这一刀**的伤害 × SwordWaveDamageRatio(0.50)   WeaponSystem.cs:403
飞行距离        = 攻击范围 × SwordWaveDistMult(1.25)             RunSession.cs:4659
飞行速度        = SwordWaveSpeed = 18 米/秒                      RunSession.cs:4666
寿命（派生）    = 飞行距离 / 速度                                 RunSession.cs:4681
判定框          = 前向半长 range×0.5、横向半宽 range×sin(arc/2)
能打到最远处    = 攻击范围 + 飞行距离
开局实测（range 3.8）：距离 4.75 米｜寿命 0.2639 秒｜最远 8.55 米
                       半宽 = 3.8 × sin50° = 2.911 米
```

**灼烧（`hoe_burn`，amount = 0.5 /层/秒，amount2 = 1，maxStack 3）**

```
每层每秒伤害 = 近战命中值 × amount(0.50)
层数         = BurnLayersPerHit += 插件层数（≤3）
持续         = 由 StatusRuntime.Apply 读 formula.ailmentTickCount(3) × tickInterval(1.0) = 3 秒
开局（锄头 4 伤、1 层）：4 × 0.5 = 2.0 点/秒，共 3 跳 = 6.0
```
