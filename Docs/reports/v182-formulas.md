## 一、玩家攻击（三把武器）

### 1.1 单次伤害

```
每刀伤害 = (工具 baseValue + player.meleeDamage) × atkMult × 暴击倍率
```
- `[码]` 锄头 `baseValue 3` ＋ `player.meleeDamage 1` ⇒ **每刀 4**（`atkMult 1.0`、无暴击）
- `[算]` 玩家裸装 DPS = 4 ÷ 0.7s = **5.714**

### 1.2 攻击间隔

```
刀间隔 = tool.cooldown / player.attackSpeed
```
- `[码/测]` 锄头 `0.7 / 1.0 = 0.70s` ｜ 水壶 `0.80s` ｜ 肥料 `1.20s`（菜单详情行实测读数）

### 1.3 攻击范围

```
实际射程 = tool.range × player.atkRange
```
- `[码]` 与 `RunSession.WeaponRange` 同一式子
- `[测]` 锄头 **3.2m** ｜ 水壶 **9.5m** ｜ 肥料 **6.5m**

### 1.4 暴击

```
暴击率 = Clamp01(player.critRate + Σ道具 CritRate)    ← 0..1 小数，不是百分点
命中时 Rng.Chance(暴击率) ⇒ 暴击伤害 × (1 + critDamage)
```
- `[码]` 两个消费点都加了 `Mathf.Clamp01`（v181 加的，`RunSession.cs:3951` / `:4174`）
- **v182 起 `player.critRate` 初始值 0 → 0.05**
- `[测]` v181 修复后实测：装 +6% 道具 ⇒ **53/1000 = 5.30%**（期望 6%，偏差 1σ 内）
- ⚠️ **教训**：升级卡里的 `amount` 是**整数百分点**，写进 `Stats` 前要 `/100f`（`IsFractionStat` 判定）；v180 曾因漏这一步把 +3 当成 +300% ⇒ 钳成 1.0 ⇒ **每刀必暴**

### 1.5 剑气（插件 `hoe_swordwave`）

```
剑气射程 = 实际射程（tool.range × atkRange）
剑气判定宽度 = 近战判定框同尺寸
剑气伤害 = 每刀伤害 × 1.0（全额，与近战同）
```
- `[码]` v182 前：一条细线，只打"正好在线上"的敌人 ⇒ 用户报"无效"
- v182 改为**同宽矩形/胶囊**向前发射（本轮的修复项）

### 2.2 波次成长

设 `t = wave − 1`：

```
HP(w)      = baseHp      × (1 + 0.12·t + 0.006·t²)
单击(w)    = touchDamage × (1 + 0.08·t + 0.003·t²)
```
- `[码]` `hpStepA 0.12 / hpStepB 0.006 / dmgStepA 0.08 / dmgStepB 0.003`
- **刻意未动**（只降起点、保留坡度）

## 三、难度裕度（我用来判断"第几波扛不住"的判据）

```
玩家 EHP      = maxHp + shield = 10 + 2 = 12
单怪受击间隔  = max(touchCooldown 0.8, invulnTime 1.0) = 1.0s   （v180 起）
每刀伤害      = 4
裕度(w) = ( ⌈EHP / 单击(w)⌉ × 受击间隔 ) / ( ⌈HP(w) / 每刀伤害⌉ × 刀间隔 )
```
- **裕度 < 1 ⇒ 打不死先倒下**
- `[算]` 分水岭：改前 **第 16→17 波** ⇒ 改后 **第 24→25 波**（**+8 波**）
- `[算]` 多怪同时贴脸时受击 DPS：`1.0/0.6 = 1.667` ⇒ `0.7/1.0 = **0.700**`（**−58%**）

### 3.1 玩家受击

```
无敌时长 = player.invulnTime = 1.0s   （v180：0.6 → 1.0）
受击半径 = ScaledRadius(0.50) × HitRadiusScale 1.486 = 0.7430m
受击面积 = πr² = 2.667 → **1.734 m²**（**−35.0%**）
```
- `[测]` 半径 `0.9213 → 0.7430 m`（−19.4%）
- 判定全走 `Actor.Radius`（本项目**无 Unity Collider 参与命中**）

## 四、经济

### 4.1 商店实付价（★ 玩家喊"贵"看的是这个，不是 `price`）

```
实付 = price × 档位倍率 × 1.13^(wave − 1)
档位倍率：D 1.0 ／ C 1.8 ／ B 3.2 ／ A 5.6 ／ S 9.0
```
- `[码]` `RunSession.ShopPriceFrom` ＋ `Defs.QualityDef.PriceMult`
- `[测]` 道具：旧表 C 档实付 **50~61** ／ B 档 **147~186** ⇒ v180 降价后 C **12.6~16.2** ／ B **32~48**
- `[测]` 插件：v182 前 S 档第 3~5 波已 **300+** ⇒ v182 目标 **110~140**

### 4.2 刷新价（商店刷新 ＋ 抽卡重抽同一口径）

```
刷新价(n) = base × 2^n        n = 本次第几次刷新（0 开始）
上限      = base × RerollMaxMult(8) = base × 8
```
- `[码/测]` base = 3 ⇒ **3 → 6 → 12 → 24 → 24 → 24 → 24 → 24**
- 依据：**顶价 24 ≈ 0.4 回合收入**；不封顶时第 8 次 = 768 = **12.8 回合**

### 4.3 每回合收入

```
收入 = 株数 × goldYield(档) × 生长周期 × 等级倍率
```
- `[测]` 实测锚点（seed 5454 / Farmer）：**收割 389 次 = +1276 金 ／ 533 秒 ⇒ 143.7 金/回合**（末段 6 株、含等级 ×1.35/1.70）
- `[码]` 档位每秒金：**D 0.250 ／ C 0.400 ／ B 0.700 ／ A 1.000 ／ S 1.440**（同档四象限极差 **0.00%**）
- `[算]` 参考收入 **R = 60 金/回合**（≈ 4 株 D 档的早期扩张态）
- `[算]` D 档单株 = **15 金/回合**（0.250 × 60s）

### 4.4 道具可买几件（验收判据）

```
件数 = R ÷ 实付价
```
- `[测]` D **10~12** ／ C **3.7~4.8** ／ B **1.2~1.9**
- 判据：**低品质（D/C）每回合能买 ≥3 件** ✗ **中品质（B）≥1 件**

## 五、种植

```
生长时间  = 档位成熟时间（D 最快 / S 最慢）
水量上限  = WaterMaxFor(档) = 100 ／ 140 ／ 180
漏水      = WaterDrain（"每 5 秒"）
种下时    = 满水
```
- `[测]` **当前 `Thirsty` 永远不为真**：
  - 漏水 `6 / 5s` ⇒ 从 100 到 0 要 **83 秒**
  - 而水**只在生长期漏**，最慢作物 **32 秒就熟**
  - 实测 `PlotDump`：`剩余1.3s 水=98/100`、`剩余3.7s 水=88/100`
- ⚠️ **所以"缺水"这个机制现在形同不存在**（缺水弹字与缺水箭头都不出现）
- 修法（任选一个数）：`waterDrain 6 → 24`（21 秒断水）或 `waterMax 100 → 40`
