# Seedfall 守园者 · 每分钟数值表（计时制）

> 计时制方案：**回合 → 分钟**。`WaveIndex` 变成 `MinuteIndex + 1` 的派生量，
> 既有全部成长曲线（`1+a·t+b·t²`、√、几何价格）**一行不改**，自动从"20 回合封顶"变成"无限"。

---

## 一、全部公式

```
t = 分钟 − 1

敌人 HP    = 基础血 × (1 + 0.12·t + 0.006·t²)          无上限
敌人伤害   = 基础值 × (1 + 0.08·t + 0.003·t²)          无上限
额外存活   = ⌊9.8  × √t⌋                              数量用 √（后期减速，防性能悬崖）
额外刷新   = ⌊3.67 × √t⌋
商品价格   = 基础价 × 稀有度倍率 × 1.13^t               几何增长
出售价     = 当前分钟实际价格 × 40%
重抽价     = 3 + 2·t
```

**为什么数值加速、数量减速**：数量加速会撞性能悬崖，而且"人海"比"变硬"更快摧毁手感。
两者形状刻意相反，但**都不封顶** —— 只要时间还在走，就还在成长。

## 五、`WaveIndex` 的兼容性说明

```csharp
public float GameTime;                        // 唯一时间真值
public int   MinuteIndex => (int)(GameTime / 60f);
public int   WaveIndex   => MinuteIndex + 1;  // 保留旧名字，语义变成"第几分钟"
```

**收益**：30+ 处引用 `WaveIndex` 的代码（数值/价格/刷怪/商店/品质）**一行不改**，
`GameTime` 无上限 → **自动无限** ✓

**安全网**：自检里有一条"第 N 分钟的数值必须等于旧版第 N 回合" ✓
**如果这条不等，说明有地方绕过了 `WaveIndex` 自己算时间。**
